# 雷霆战机 · Thunder Fighter

纯前端单文件的 2D 竖版飞行射击游戏，原生 Canvas 绘制，零依赖、零构建。**手机可触屏玩**，双击 `index.html` 就能跑。

![genre](https://img.shields.io/badge/genre-vertical%20shmup-4de6ff) ![mobile](https://img.shields.io/badge/mobile-touch%20ready-7cffb2) ![license](https://img.shields.io/badge/license-MIT-ffd166)

## 操作

**手机 / 平板**：按住屏幕任意位置拖动即可移动战机（手指下方会自动留出偏移，不会挡住飞机）；自动开火；右下角橙色圆钮 = 释放炸弹，右上角 ❚❚ = 暂停。

**电脑**：`W A S D` / 方向键移动，鼠标拖拽也能移动；`J` / `X` 炸弹；`P` / `Esc` 暂停；`M` 静音；`Enter` / 空格 开始或重开。

## 火力等级（吃 P 升级，最高 Lv8）

| 等级 | 武器 | 说明 |
| --- | --- | --- |
| Lv1 | 单发主炮 | 1 发直射 |
| Lv2 | 双发主炮 | 2 发平行 |
| Lv3 | 三发齐射 | 中央强化弹 + 两侧各 1 发 |
| Lv4 | 交叉火力 | 3 发直射 + 两侧斜射散开 |
| Lv5 | 追踪导弹 x2 | 新增 2 枚自动锁敌导弹 |
| Lv6 | 追踪导弹 x4 | 左右各再加 1 枚 |
| Lv7 | 追踪导弹 x6 | 左右各再加 1 枚 |
| Lv8 | 激光炮 | 机体宽度的一条纵向贯穿激光，连续伤害 |

伤害基准：Lv4 主炮为 1 倍 → 追踪导弹 = **2 倍** → 激光 = **4 倍**（每 0.1 秒结算一次，且会烧掉光柱内的敌弹）。

## BOSS（三种，按你当时的火力选）

| BOSS | 触发条件 | 特点 |
| --- | --- | --- |
| 人类舰队旗舰 | 火力 < 5 | 原风格：九连扇形 → 瞄准连射 → 环形 + 螺旋弹，残血召僚机 |
| 虫族母巢 | 火力 ≥ 5 | 异形甲壳：分节甲片、步足、发光卵囊、下颚巨钳；酸液扇射 + 瞄准毒刺 + 孵化翼虫 |
| 机械母舰 | 火力 ≥ 8 | 约半个屏幕宽的航天母舰：双炮塔扇射、机库放机甲、环形弹幕 |

每关末尾进入 BOSS 战，都有入场动画与三段血量阶段。

## 道具

- **P** 火力升级（Lv1→Lv8）
- **B** 补充炸弹（上限 6）
- **S** 8 秒护盾，可抵挡一次伤害

## 技术要点

- 单文件 HTML，CSS / JS 全内联，无外部依赖、无网络请求，断网也能玩
- 480 × 800 逻辑分辨率，按 `devicePixelRatio` 适配；舞台尺寸同时受 `100vw` / `100dvh` 约束，手机窄屏不会被裁切
- 全部画面（战机、各型敌机、BOSS、子弹、爆炸、星空）均为 Canvas 路径与渐变实时绘制，无贴图
- 音效用 WebAudio 实时合成（振荡器 + 噪声缓冲），无音频文件
- 触屏优化：`touch-action:none`、禁用双击缩放与双指缩放、`pointer` 事件统一处理鼠标与手指
- 为手机性能考虑：子弹/敌弹改用实心分层绘制，避免每颗子弹创建渐变

## 运行

```bash
# 直接双击
index.html

# 或起个本地服务
python -m http.server 8000   # http://localhost:8000
```

### 用手机玩 / 发给别人

- **最稳**：发在线链接 `https://mrdiaomark.github.io/thunder-fighter/`，微信里点开就能玩。
- **直接传 .html 文件**：安卓上收到后点「用其他应用打开」→ 选浏览器即可；微信的「文件预览」有些版本不执行脚本，会停在标题页（页面底部会提示这条），按提示点「···」→「在浏览器打开」就行。
- 已经做过兼容：`localStorage` 全部包了 try（file:// 下常被判不安全）、补了 `ctx.roundRect` 兜底（老内核缺这个 API 会整屏报错）、单帧异常不再中断游戏、出错会弹一条提示而不是黑屏。
